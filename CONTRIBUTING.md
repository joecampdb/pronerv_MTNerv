# Contributing

Open an issue with the scientific question or reproducible software bug. Submit
changes on a branch, with a pull request explaining behavior, scientific assumptions,
provenance changes, validation and before/after figures where relevant.

Keep trajectories, credentials, virtual environments and simulation outputs out
of commits. Do not interpret pooled occupancy as validated equilibrium free energy,
or formal compositions as observed trajectories.

Run the tests in `alanine-nerve/README.md`. For analysis changes, regenerate assets,
update the paper's counts and limitations, and inspect the rendered PDF. Retain
deterministic selection, seeds, exact source member names and hashes.
The polyethylene workflow is independent; preserve its protocol and outputs.
